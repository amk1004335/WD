# Student Project - Web Development1

## 📌 Project Overview
This is a web application developed using the **SCRUM methodology**. The team will implement various features and demonstrate progress at the end of each sprint.

## 🚀 Project Plans
### Features to Implement:
- **User Authentication** (Login, Register)
- **Product Management** (CRUD: Add, Edit, Delete Products)
- **Order Management** (Order creation & tracking)
- **Admin Panel** (Protected with `.htaccess`)

## 🗂 Database Design
- `users` table (User login details)
- `products` table (Product information)
- `orders` table (Tracks orders)
- Relationships: **Users → Orders, Orders → Products**
  
📌 **A PhpMyAdmin diagram will be added later.**

## 🔧 Features Implemented (Progress)
- **Week 1:** Database setup, user authentication.
- **Week 2:** CRUD operations for products.
- **Week 3:** Order management system.
- **Week 4:** JavaScript validation & final testing.

## 💡 Technologies Used
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP, MySQL  
- **Tools:** VS Code, GitHub, PhpMyAdmin
